# CleanEkiti Admin Quick Reference Card

## Daily Workflow Checklist

### 🌅 Morning Routine (15 minutes)
- [ ] Login to admin dashboard: `[your-domain]/admin/login`
- [ ] Check overnight reports (red badges indicate new reports)
- [ ] Review urgent reports (flooding, pollution, health hazards)
- [ ] Assign reports to appropriate departments

### 📋 Report Management

#### Viewing Reports
- **All Reports**: Main dashboard shows recent reports
- **Filter by Status**: Pending | Investigating | Resolved
- **Filter by Category**: Dumping | Flooding | Pollution | Drainage | Other
- **Search**: Use location names or keywords

#### Updating Report Status
1. Click **"View"** on any report
2. Choose appropriate status:
   - **Investigating**: Team dispatched/work started
   - **Resolved**: Issue completely fixed
   - **Pending**: Needs more information/resources
3. Status automatically updates for citizen

#### Priority Levels
- **🔴 Urgent**: Health hazards, major flooding, toxic spills
- **🟡 Medium**: Blocked drainage, illegal dumping
- **🟢 Routine**: Minor issues, maintenance requests

### 📊 Dashboard Statistics

#### Key Metrics (Top of Dashboard)
- **Total Reports**: All-time submissions
- **Pending**: Awaiting action
- **Investigating**: Work in progress  
- **Resolved**: Completed issues

#### Performance Targets
- **Response Time**: < 24 hours for urgent, < 72 hours routine
- **Resolution Rate**: > 85% within 30 days
- **Citizen Satisfaction**: Monitor feedback and repeat reports

### 🚨 Emergency Procedures

#### Urgent Environmental Issues
1. **Immediate Action**: Contact relevant emergency services
2. **Update Status**: Mark as "Investigating" immediately
3. **Document Response**: Add notes about actions taken
4. **Follow Up**: Update status to "Resolved" when complete

#### System Issues
- **Can't Login**: Check internet connection, try different browser
- **Reports Not Loading**: Refresh page, check system status
- **Technical Problems**: Contact IT support immediately

### 📱 Mobile Access
- Dashboard works on smartphones and tablets
- Same login credentials as desktop
- All features available on mobile
- Recommended for field staff updates

### 👥 User Management

#### Admin Account Types
- **Super Admin**: Full system access, user management
- **Department Admin**: Specific category access
- **Field Staff**: Status updates only

#### Security Best Practices
- **Strong Passwords**: Minimum 8 characters, mixed case, numbers
- **Regular Logout**: Don't leave sessions open
- **Secure Access**: Only use trusted devices/networks
- **Report Suspicious Activity**: Unusual login attempts or data

### 📈 Weekly Reporting

#### Generate Reports
1. **Performance Summary**: Resolution rates, response times
2. **Geographic Analysis**: Problem areas, resource needs
3. **Trend Identification**: Recurring issues, seasonal patterns
4. **Resource Planning**: Staff allocation, equipment needs

#### Key Questions to Answer
- Which areas have most reports?
- What types of issues are most common?
- How quickly are we responding?
- Are issues being resolved effectively?

### 🔧 Common Tasks

#### Adding Internal Notes
- Click "View" on report → Add notes section
- Document actions taken, resources used
- Communicate with other departments
- Track progress over time

#### Handling Duplicate Reports
- Check location and description for similarities
- Mark duplicates as "Resolved" with note: "Duplicate of Report #XXX"
- Focus resources on original report

#### Photo Management
- All photos automatically stored and backed up
- Use photos to assess issue severity
- Take "after" photos when issue resolved
- Photos help with resource planning

### 💡 Pro Tips

#### Efficiency Shortcuts
- **Keyboard Navigation**: Tab through reports quickly
- **Bulk Updates**: Handle similar reports together
- **Status Templates**: Use consistent language for updates
- **Photo Evidence**: Always document completed work

#### Citizen Communication
- **Be Responsive**: Update status within 24 hours
- **Be Specific**: "Road cleared" vs "Issue resolved"
- **Be Honest**: If delayed, explain why
- **Be Appreciative**: Thank citizens for reporting

#### Data Quality
- **Accurate Locations**: Verify addresses when possible
- **Clear Categories**: Ensure proper classification
- **Complete Information**: Don't leave fields blank
- **Regular Cleanup**: Archive old resolved reports
